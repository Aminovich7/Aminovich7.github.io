A marketplace API for goods sold by the kilogram, litre or box: listings, requests for quotation, offers, orders and an admin moderation API.

A marketplace for goods sold in bulk units, from kilograms of produce to boxes of handmade goods. Sellers list goods; buyers either order directly or post a request for quotation that sellers answer with offers. A small JavaScript frontend sits on top of the API.

What it does

  • Listings with categories, regions, fixed or negotiable prices, search, filters and expiry.
  • Requests for quotation and offers, validated against the request they answer.
  • An order workflow from pending to completed, with cancellation while pending or confirmed.
  • Seller verification and an admin API for moderation and marketplace statistics.
  • JWT with a token blacklist for logout, role-based permissions and throttling.

Stack
