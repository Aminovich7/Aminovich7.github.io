A freelance marketplace API in the style of Upwork. Clients post projects, freelancers bid on them, and an accepted bid becomes a contract that either side can cancel. Both sides leave reviews when the work is done.

What it does

  • Users and profiles for clients and freelancers, with skills and categories.
  • Projects and bids with filtering and search.
  • Contracts and reviews created from accepted bids.
  • JWT authentication, OpenAPI docs, and a Postman collection for the main flow: register, post a project, bid, accept, finish and review.

Stack

  • Django REST Framework
  • SimpleJWT
  • django-filter
  • drf-spectacular
  • PostgreSQL
